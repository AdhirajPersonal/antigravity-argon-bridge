## Project Status & Deprecation Notice

As of **October 26, 2026**, **Antigravity Argon Bridge has been permanently unpublished from the VS Code Marketplace and the Open VSX Registry, and this repository has been archived.**

### Why was this project taken down?
Antigravity Argon Bridge was created as an experimental bridge and proof-of-concept to provide developers and autonomous coding agents access to high-depth reasoning models through persistent browser sessions and CDP-driven automation. 

While the project gained significant interest and adoption in a short period of time, **automated browser driving and session emulation across Google accounts carry inherent security and account suspension risks for end users**. 

As maintainers, prioritizing the safety, privacy, and account security of our users outweighs popularity metrics. Rather than putting users at risk of sudden account blocks, session invalidations, or TOS flags, the decision was made to safely sunset the project and pull it from all extension registries.

1. Use official developer APIs (e.g. Google AI Studio / Gemini API) with standard API keys.
2. Leverage official MCP connectors that adhere strictly to provider-sanctioned API access.
